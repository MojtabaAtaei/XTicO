# XTicO

A simple Tic-Tac-Toe game made with Python that you can play in the terminal.

## Features

- Play against the computer
- Checks for a winner
- Prevents invalid moves
- Simple computer moves
- Colored terminal output

## Requirements

- Python 3.x
- termcolor

## Installation

Clone the repository and install the required package:

```bash
pip install -r requirements.txt
```

## Run

Start the game with:

```bash
python main.py
```

## How to Play

The game uses numbers from 1 to 9 for the board.

Choose a number and press Enter to make your move.
