# XTicO

A colorful command-line Tic-Tac-Toe game written in Python.

![Python](https://img.shields.io/badge/Python-3.12%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![Version](https://img.shields.io/badge/Version-1.0.8.0-orange)

## 📖 About

XTicO is a terminal-based Tic-Tac-Toe game with a computer opponent,
timed moves, colorful output, and score tracking across rounds.

## 📸 Gameplay

![XTicO Gameplay]([screenshots/gameplay.png](https://github.com/MojtabaAtaei/XTicO/blob/main/Screenshot/gameplay.png)

## ✨ Features

- 🎮 Interactive Tic-Tac-Toe gameplay
- 🤖 Computer opponent
- 🎨 Colorful terminal UI
- ⏱️ 60-second move timer
- 🏆 Score tracking
- 🔁 Multiple rounds
- ✅ Input validation

## 🖥️ Requirements

- Python 3.12+
- `termcolor`, `inputimeout`

## 🚀 Installation

```bash
git clone https://github.com/MojtabaAtaei/XTicO.git
cd XTicO
pip install -r requirements.txt
```

## 🎯 Usage

```bash
python main.py
```
