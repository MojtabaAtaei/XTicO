# Changelog

All notable changes to **XTicO** are documented in this file.

## [1.0.8.0] - 2026-10-17

### Added
- Command-line Tic-Tac-Toe gameplay
- Computer opponent (win / block / preferred-move logic)
- Colorful terminal UI using termcolor
- 60-second move timer with random-move fallback
- Score tracking across multiple rounds
- Round counter
- Input validation for player moves
- Draw detection
- Play-again prompt with timeout
- Graceful KeyboardInterrupt handling
- Custom InvalidMoveError exception

### Notes
- RequiPython 3.12+2+** (uses PEP 701 f-string syntax)
